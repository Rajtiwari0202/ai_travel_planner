# Five-Minute Demo Script

1. Open the frontend at `http://localhost:5173`.
2. Show provider status and explain that paid APIs are not required.
3. Create a Mumbai to Goa trip with dates, travelers, budget, and interests.
4. Point out backend-streamed agent events.
5. Review itinerary days, weather labels, source labels, map markers, budget reconciliation, and optimization score.
6. Revise the plan with: `add more adventure`.
7. Export the itinerary JSON.
8. Open the methodology page and explain limitations.
