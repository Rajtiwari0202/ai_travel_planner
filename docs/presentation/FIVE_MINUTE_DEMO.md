# Five Minute Demo

Input:

- Origin: Mumbai
- Destination: Goa
- Dates: July 10-12, 2026
- Travelers: 2
- Budget: INR 45,000
- Interests: beach, food, culture

Flow:

1. Submit the planner form.
2. Point out agent progress streaming.
3. Open itinerary, budget chart, and map.
4. Revise with: `add more adventure`.
5. Export JSON.

Fallback if backend is waking up: explain the readiness banner and retry.

Data note: prices are estimates, not live booking inventory.
