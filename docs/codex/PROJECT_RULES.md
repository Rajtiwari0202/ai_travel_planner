# Project Rules

- Keep the app local-first and zero-cost by default.
- Preserve estimated-data labels; never imply booking-grade live prices.
- Keep source, generated research artifacts, and local runtime data clearly separated.
- Prefer environment-driven configuration over hardcoded URLs.
- Keep public demo data anonymous and scoped to the browser session owner.
- Treat research outputs as reproducible draft evidence, not peer-reviewed claims.
- Record significant cleanup, deployment, and verification work under `docs/audits/`.
