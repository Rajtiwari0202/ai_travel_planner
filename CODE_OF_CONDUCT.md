# Code of Conduct

This project follows a simple standard: be respectful, constructive, and honest.

## Expected Behavior

- Use welcoming and inclusive language.
- Focus critique on the work, not the person.
- Be truthful about data sources, limitations, and verification status.
- Avoid sharing secrets, private data, or personal travel information in issues or pull requests.

## Unacceptable Behavior

- Harassment, insults, or discriminatory language.
- Publishing secrets, credentials, or private user data.
- Misrepresenting estimated travel data as live booking inventory.

## Enforcement

Maintainers may remove comments, close issues, or block participation when behavior harms the project or its users.
